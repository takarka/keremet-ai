# Jev и Perplexity Decider: исследование (2026-10-15)

## Что это
- **Decision-модели** `typesafe/jev-1.14` и `perplexity/pplx-decider-v1.1-27b`: не генерируют текст, а отвечают на типизированные вопросы (`noul` — да/нет с вероятностью, `choice`, `score`, `box`) через `POST /api/alpha/decisions`. Выход бесплатный, вход ~$0.02–0.04 за 1M токенов.
- **`typesafe/jev-router`**: обычный chat-эндпоинт, сам выбирает модель и reasoning effort по тексту промпта (картинки не учитывает). Цена в каталоге `-1`, реальная — в `usage.cost`.

## Оговорки
- Выборка маленькая, размечена вручную и без реальных экранов: цифры оптимистичны, это проверка «API работает и различает базовые случаи», а не доказательство надёжности.
- Скриншоты не проверялись: формат изображения в `state` в документации не описан.

Роутер за 3 запроса выдал 131 156 выходных токенов (выбрал тяжёлое рассуждение) и не успел сделать ни одного действия. Реальные деньги малы, но время неприемлемо; наша оценка бюджета для моделей с переменной ценой использует запасные цены из `.env` и сработала как защита (ложно «$2.00»). **Вывод: `jev-router` как LLM агента не подходит** (задержка и непредсказуемое рассуждение на каждом шаге); оставляем `claude-haiku-5.5`.

## Вывод для внедрения
Идея A (второй слой Payment Guard, только добавляет остановки) выглядит рабочей: задержка <1 с, стоимость ничтожна. Перед внедрением нужны: датасет реальных экранов (с a11y-текстом), узкая формулировка вопроса про отправку, замер `jev-router` против Haiku.

## Внедрено после замера: второй слой Payment Guard
`security/decider_guard.py` + `GuardedDriver(decider=...)`: после regex-проверки подпись кнопки и тексты экрана уходят в decision-модель (`DECIDER_MODEL`, по умолчанию выключено); вероятность ≥ `DECIDER_THRESHOLD` (0.5) для платежа/удаления → остановка и Approval Gate. Только добавляет остановки; сбой API не блокирует и не разрешает (решает regex). Кэш по (подпись, контекст). 8 тестов. Включение: `DECIDER_MODEL=typesafe/jev-1.14` в `.env`. Живой проверки на реальном экране оплаты ещё не было.
