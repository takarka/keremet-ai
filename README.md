# Keremet — Hands-Free Phone Agent

Агент, который выполняет задачи в приложениях на Android-телефоне по текстовой или голосовой команде (терминал или Telegram). Управляет телефоном через ADB и [Mobilerun](https://github.com/droidrun/droidrun) Portal, думает через OpenRouter.

**Главное правило: Prepare & Approve.** Агент готовит действие (корзина, форма, счёт), но оплату, перевод, удаление и отправку подтверждает только человек. Агент никогда не вводит PIN, коды и биометрию.

Документация: [`docs/PLAN.md`](docs/PLAN.md) (план), [`docs/PROGRESS.md`](docs/PROGRESS.md) (статус, KPI, журнал решений), [`prd_mobile_ai_assistant.md`](prd_mobile_ai_assistant.md) (требования).

## Что нужно

- Windows 10/11 (проверено на Windows 11), Python 3.12+, [uv](https://docs.astral.sh/uv/), Android Platform Tools (`adb`).
- Android-телефон (проверено: Redmi Note 9 Pro, Android 10, MIUI) с USB-отладкой.
- Ключ [OpenRouter](https://openrouter.ai/keys). Для Telegram-бота — токен от [@BotFather](https://t.me/BotFather); для голоса — ключ Whisper-совместимого STT (например, Groq).

## Установка

```powershell
winget install Python.Python.3.12 astral-sh.uv Google.PlatformTools
git clone <репозиторий> keremet-ai ; cd keremet-ai
uv sync
copy .env.example .env      # затем заполните .env (см. ниже)
```

Новые программы появятся в `PATH` только в новой оболочке. Сам `adb` агент находит и без `PATH` (ищет в пакете WinGet).

### Телефон

1. **Настройки → О телефоне** → 7 раз нажмите на версию MIUI/сборку → появятся «Для разработчиков».
2. **Для разработчиков**: включите «Отладка по USB». На MIUI также «Установка по USB» и «Отладка по USB (настройки безопасности)».
3. Подключите кабель, на телефоне подтвердите ключ RSA. Проверка: `adb devices` → строка `device`.
4. Если установка Portal блокируется проверкой приложений (`INSTALL_FAILED_VERIFICATION_FAILURE`), временно отключите Play Protect («Проверять приложения» в Google Play → Play Protect) и включите обратно после установки.
5. Установите Portal: `uv run mobilerun setup`, затем на телефоне включите **Службы доступности → Mobilerun Portal**. Проверка: `uv run mobilerun ping`.
6. **MIUI убивает службу доступности.** Для Portal: «Автозапуск» — включить, «Контроль активности» — «Нет ограничений», закрепите приложение в «Недавних». Если служба всё же умерла, агент пробует её оживить сам (до 3 раз за задачу).
7. Для приложений из `config/allowlist.yaml` войдите в аккаунты вручную (банк, доставка и т. п.).

### Подключение по Wi-Fi (без кабеля)

Телефон и компьютер — в одной сети. Один раз по кабелю:

```powershell
adb tcpip 5555
adb connect 192.168.1.119:5555     # IP телефона: adb shell ip -f inet addr show wlan0
```

Впишите `ANDROID_SERIAL=192.168.1.119:5555` в `.env`. Дальше раннер сам делает `adb connect` перед каждой задачей. После перезагрузки телефона режим TCP сбрасывается — повторите `adb tcpip 5555` по кабелю. IP из DHCP может смениться — закрепите его в роутере. В чужих и публичных сетях выключайте режим: `adb usb`.

## Настройка `.env`

| Переменная | Назначение |
| :--- | :--- |
| `OPENROUTER_API_KEY` | ключ OpenRouter (обязательно) |
| `LLM_MODEL` | модель; по умолчанию `anthropic/claude-haiku-5.5`. Цены берутся из каталога OpenRouter автоматически |
| `ANDROID_SERIAL` | серийный номер из `adb devices` или `ip:порт` для Wi-Fi |
| `MAX_COST_USD` / `MAX_SECONDS` | жёсткие лимиты одной задачи: стоимость в $ (0.25) и время в секундах (300) |
| `TELEGRAM_BOT_TOKEN`, `TELEGRAM_ALLOWED_USER_IDS` | токен бота и список разрешённых Telegram ID через запятую (чужие игнорируются) |
| `STT_API_KEY`, `STT_BASE_URL`, `STT_MODEL`, `STT_LANGUAGE` | распознавание голоса (OpenAI-совместимый `/audio/transcriptions`) |
| `SECRETS_KEY` | ключ шифрования хранилища секретов |
| `DECIDER_MODEL`, `DECIDER_THRESHOLD` | необязательный второй слой защиты (см. ниже); пусто = выключен |

Файл `.env` не попадает в git. Не присылайте ключи и PIN в чаты.

## Запуск

### Из терминала

```powershell
uv run python -m agent run "Открой Telegram и скажи, какой раздел открыт" --dry-run   # проверить настройки, телефон не трогает
uv run python -m agent run "Открой Telegram и скажи, какой раздел открыт"
```

Флаги `run`: `--model`, `--serial`, `--vision` (скриншоты на всех экранах), `--steps` (по умолчанию 30), `--max-cost`. Для приложений, где нужный текст не виден в дереве элементов (2ГИС), `--vision` включается автоматически. Итог: статус (`success`, `failed`, `payment_stop`, `stuck`, `budget_exceeded`, `timeout`, `error`), ответ агента, шаги, время, токены и стоимость. Журнал — в `runs/<task_id>/`.

### Telegram-бот

```powershell
uv run python -m gateway.telegram_bot
```

Отправьте боту текст или голосовое сообщение. Голос сначала показывается как распознанный текст с кнопками «Выполнить / Отмена». Перед оплатой, удалением и отправкой бот присылает скриншот и кнопки «Подтвердить / Отменить» (таймаут 15 минут). После изменения кода или `.env` бота нужно перезапустить.

### Секреты (паспорт, адрес и т. п.)

```powershell
uv run python -m security.secret_store init          # создать SECRETS_KEY, добавьте его в .env
uv run python -m security.secret_store set passport.number   # значение вводится скрыто
uv run python -m security.secret_store list
```

В задаче пишите `{{secret:passport.number}}`: модель видит только метку, подстановка происходит локально перед вводом.

### База знаний

Карточки приложений лежат в `knowledge/app_cards/android/`, алиасы названий — в `knowledge/aliases.json`. Агент подмешивает карточку к задаче, если в ней упомянуто приложение.

```powershell
uv run python -m agent note kz.kaspi.mobile "Корзина — вкладка Себет, окно «OK» закрыть"
uv run python -m agent notes
```

## Безопасность

- **Allowlist** (`config/allowlist.yaml`): агент открывает только перечисленные приложения; настройки, установщики, Play Store и сам Portal заблокированы. Установка и удаление приложений агентом запрещены.
- **Payment Guard**: тап по кнопке оплаты, удаления или отправки (текст или описание на русском, казахском, английском) блокируется, делается скриншот, создаётся запрос на подтверждение. Защита стоит между моделью и телефоном, поэтому промптом её не обойти; при нераспознанном экране действие не выполняется (fail-closed).
- **Второй слой** (необязательно): `DECIDER_MODEL=typesafe/jev-1.14` — decision-модель OpenRouter оценивает кнопку под тапом (около 0.7 с, меньше $0.001). Только добавляет остановки; сбой API ничего не разрешает. Подпись кнопки и тексты экрана уходят в облако.
- **Лимиты**: стоимость (`MAX_COST_USD`), время (`MAX_SECONDS`), зацикливание (одна и та же область нажата >6 раз, один текст введён >3 раз, приложение запущено >3 раз) — задача прерывается, дальнейшие действия блокируются.
- **Журнал**: `runs/<task_id>/actions.jsonl` и скриншоты. Вводимый текст не пишется, только длина.
- Банковские данные уходят в облачную модель только с вашего явного согласия. Вход в банк делаете сами.

## Замер KPI

```powershell
uv run python -m agent bench --list                       # сценарии из tests/scenarios/scenarios.yaml
uv run python -m agent bench                              # план и верхняя оценка стоимости, телефон не трогает
uv run python -m agent bench --yes                        # прогнать на телефоне
uv run python -m agent bench --only dgis-starbucks --yes
```

Флаги `--include-personal` (читает чаты) и `--include-payment` (доходит до экрана оплаты, нужны входы в аккаунты) выключены по умолчанию. Сценарии идут в отдельных процессах; приложения, которых нет на телефоне, пропускаются. Отчёт: `runs/kpi/*.md` и `.json` (успех, задержка, стоимость, перехват платежей против целей PRD).

## Если что-то не работает

| Симптом | Что делать |
| :--- | :--- |
| `adb devices` пусто / `unauthorized` | переподключить кабель, подтвердить RSA-ключ; по Wi-Fi — `adb connect <ip>:5555` |
| `Accessibility service not available` | включить Portal в «Службах доступности»; на MIUI см. п. 6 установки |
| Задача завершилась `timeout` | завис телефон или приложение; закройте приложение (`adb shell am force-stop <пакет>`) и повторите |
| Телефон завис из-за тяжёлого приложения (2ГИС со скриншотами) | закрыть приложение, освободить память, упростить задачу |
| `stuck` | сработал обрыв по зацикливанию; сформулируйте задачу конкретнее или добавьте урок в карточку приложения |
| `payment_stop` | так и задумано: подтвердите или отмените в Telegram либо нажмите кнопку сами |
| Бот не отвечает | проверьте, что ваш ID в `TELEGRAM_ALLOWED_USER_IDS`, перезапустите бота |
| Бот пишет про ошибку STT 401 | в `STT_API_KEY` должен быть ключ STT-провайдера, не OpenRouter |
